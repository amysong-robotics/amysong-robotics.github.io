# Yuzhen Song | Personal Academic Homepage

Personal academic homepage of Yuzhen Song, an undergraduate researcher in robotics at Southern University of Science and Technology.

Website: [amysong-robotics.github.io](https://amysong-robotics.github.io/)

## Content

- Academic background and contact information
- Academic paper and research work
- Robotics projects, demonstrations, figures, videos, and papers
- CV and supporting academic materials

## Local development

This website is built with Jekyll and the al-folio theme.

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## Deployment

The `main` branch is deployed automatically through GitHub Pages using the repository workflow. Site content is organized in `_pages/`, `_projects/`, `assets/`, and the theme configuration files.
